# M365 Threat Intelligence Report, 2026-08-31

Report Period: July 2026 (Target Month)
Run Date: 2026-08-31
Audience: Security Architects, SOC Leads, Cyber Leadership
Analyst Role: Senior Threat Intelligence Analyst, Microsoft 365 / Entra ID / Microsoft Cloud Stack

## Executive Summary

Five cross-source themes dominate the July 2026 M365 threat landscape.

**Device code phishing is now the defining MFA-bypass technique of 2026, with a 1,500% volume surge.** CrowdStrike measured a 15-fold increase in device code phishing through H1 2026, while vishing doubled over the same period. Campaigns like DEBULL (Storm-2372 lineage), Forg365, and Helix all exploit the OAuth 2.0 Device Authorization Flow, completing MFA authentically on the victim's behalf. Blocking the device code flow in Conditional Access is the single most impactful control available to all M365 tenants.

**Vishing is maturing into a primary initial access vector, with passkey enrollment as the new social engineering surface.** The O-UNC-066/"Pink" extortion group (Scattered Spider-adjacent) pivoted from legacy MFA vishing to impersonating IT support during Microsoft's own passkey rollout, tricking users into enrolling attacker-controlled FIDO2 keys. This inverts the security benefit of passkeys: the strongest authentication method becomes the attacker's persistent backdoor when enrollment is socially engineered.

**MaaS credential stealers now systematically target M365 session tokens and browser-stored DPAPI secrets.** The ACR Stealer (formerly Amatera Stealer) combines ClickFix social engineering, steganography-based payload delivery, and in-memory execution to harvest Edge/Chrome credentials, DPAPI-encrypted tokens, and OneDrive/SharePoint documents from enterprise endpoints — with no persistent file on disk.

**Authentication infrastructure abuse extends from email to SSPR and legacy OAuth flows.** Microsoft's Self-Service Password Reset and Resource Owner Password Credentials (ROPC) flows are being exploited for large-scale credential validation and account takeover, bypassing Conditional Access MFA enforcement in tenants with incomplete CA policy coverage.

**Microsoft's passkey-first transition (default from September 2026, SMS/voice retired February 2027) is both a defensive milestone and an active attack target.** Organizations that accelerate phishing-resistant MFA enrollment close a wide attack surface. Those that move slowly face an attack community that has already adapted social engineering playbooks to exploit the transition window.
