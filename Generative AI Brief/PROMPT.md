# Generative AI Brief — prompt

Read the root [RUNBOOK.md](../RUNBOOK.md) before executing this prompt.

Write the report in Swedish. Keep established technical terms, product names and CVE identifiers unchanged.

Produce a weekly enterprise generative AI brief covering the seven days ending on the run date in Europe/Stockholm.

Search Anthropic, OpenAI, Google DeepMind, Google AI, Azure AI blog, Hugging Face, MIT Technology Review, Ars Technica and The Register. Prioritize original announcements and research papers. Secondary reporting may establish context but must not substitute for primary evidence on technical claims.

Select 5-7 material stories when supported by the sources. Include model releases, enterprise APIs, agent systems, security, safety, governance and infrastructure. Exclude consumer-only features, gaming and minor interface changes. Read the full source before using a story; deduplicate coverage of the same announcement. Do not pad a thin week.

Use these sections: This Week in AI; Top Stories; Safety & Governance; Enterprise Features & APIs; Security Risks; Numbers That Matter; Sources. Explain what changed, enterprise implications and any decision or deadline. Include publication dates and direct source links. Only include numerical claims that the source supports. State when a section has no material development.

Save the report in this folder as `Generative AI Brief-YYYY-MM-DD.md`, using the Stockholm run date. Follow RUNBOOK.md for validation and publishing.
