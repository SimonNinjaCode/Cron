# M365 Security What's New — september 2026 (2026-10-02)

September 2026. Sammanställningen bygger enbart på de Microsoft Learn-sidor som anges nedan. Entra-sidan kräver inloggning och visar inget offentligt månadsinnehåll; Vulnerability Management-länken omdirigerar till Defender for Endpoint. Därför går det inte att verifiera separata offentliga septemberposter för dessa två tjänster. Unified SecOps-länken omdirigerar till samma Defender XDR-sida.
